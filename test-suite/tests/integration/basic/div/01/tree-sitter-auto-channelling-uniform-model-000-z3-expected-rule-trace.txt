Model before rewriting:

find a: int(0..4)
find b: int(0..4)

such that

(a / b) = 2

--

a
   ~~> select_representation ([("ReprGeneral", 10000)])
a
new variables:
  find a#bv_1: int(0..4)

--

b
   ~~> select_representation ([("ReprGeneral", 10000)])
b
new variables:
  find b#bv_1: int(0..4)

--

a
   ~~> smt_int_bv_variable ([("Smt", 9500)])
a#bv_1

--

b
   ~~> smt_int_bv_variable ([("Smt", 9500)])
b#bv_1

--

(a#bv_1 / b#bv_1)
   ~~> div_to_bubble ([("Bubble", 6000)])
{SafeDiv(a#bv_1, b#bv_1) @ b#bv_1 != 0}

--

{SafeDiv(a#bv_1, b#bv_1) @ b#bv_1 != 0} = 2
   ~~> bubble_up ([("Bubble", 8800)])
{SafeDiv(a#bv_1, b#bv_1) = 2 @ b#bv_1 != 0}

--

{SafeDiv(a#bv_1, b#bv_1) = 2 @ b#bv_1 != 0}
   ~~> expand_bubble ([("Bubble", 8900)])
and([SafeDiv(a#bv_1, b#bv_1) = 2,b#bv_1 != 0;int(1..)])

--

Final model:

find a: int(0..4)
find b: int(0..4)
find a#bv_1: int(0..4)
find b#bv_1: int(0..4)

such that

and([SafeDiv(a#bv_1, b#bv_1) = 2,b#bv_1 != 0;int(1..)])
