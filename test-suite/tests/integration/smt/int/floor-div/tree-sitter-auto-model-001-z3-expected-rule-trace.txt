Model before rewriting:

find a: int(3..4)
find b: int(1..2)

such that

(a / b) = 1

--

a
   ~~> select_representation ([("ReprGeneral", 10000)])
a
new variables:
  find a#bv_1: int(3..4)

--

b
   ~~> select_representation ([("ReprGeneral", 10000)])
b
new variables:
  find b#lia_1: int(1..2)

--

a
   ~~> smt_int_bv_variable ([("Smt", 9500)])
a#bv_1

--

b
   ~~> smt_int_lia_variable ([("Smt", 9500)])
b#lia_1

--

(a#bv_1 / b#lia_1)
   ~~> div_to_bubble ([("Bubble", 6000)])
{SafeDiv(a#bv_1, b#lia_1) @ b#lia_1 != 0}

--

{SafeDiv(a#bv_1, b#lia_1) @ b#lia_1 != 0} = 1
   ~~> bubble_up ([("Bubble", 8800)])
{SafeDiv(a#bv_1, b#lia_1) = 1 @ b#lia_1 != 0}

--

{SafeDiv(a#bv_1, b#lia_1) = 1 @ b#lia_1 != 0}
   ~~> expand_bubble ([("Bubble", 8900)])
and([SafeDiv(a#bv_1, b#lia_1) = 1,b#lia_1 != 0;int(1..)])

--

Final model:

find a: int(3..4)
find b: int(1..2)
find a#bv_1: int(3..4)
find b#lia_1: int(1..2)

such that

and([SafeDiv(a#bv_1, b#lia_1) = 1,b#lia_1 != 0;int(1..)])
