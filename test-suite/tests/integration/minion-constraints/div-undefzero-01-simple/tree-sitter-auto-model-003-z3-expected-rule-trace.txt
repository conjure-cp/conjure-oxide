Model before rewriting:

find x: int(1..10)
find y: int(2..4)

such that

(x / y) = 5

--

x
   ~~> select_representation ([("ReprGeneral", 10000)])
x
new variables:
  find x#lia_1: int(1..10)

--

y
   ~~> select_representation ([("ReprGeneral", 10000)])
y
new variables:
  find y#lia_1: int(2..4)

--

x
   ~~> smt_int_lia_variable ([("Smt", 9500)])
x#lia_1

--

y
   ~~> smt_int_lia_variable ([("Smt", 9500)])
y#lia_1

--

(x#lia_1 / y#lia_1)
   ~~> div_to_bubble ([("Bubble", 6000)])
{SafeDiv(x#lia_1, y#lia_1) @ y#lia_1 != 0}

--

{SafeDiv(x#lia_1, y#lia_1) @ y#lia_1 != 0} = 5
   ~~> bubble_up ([("Bubble", 8800)])
{SafeDiv(x#lia_1, y#lia_1) = 5 @ y#lia_1 != 0}

--

{SafeDiv(x#lia_1, y#lia_1) = 5 @ y#lia_1 != 0}
   ~~> expand_bubble ([("Bubble", 8900)])
and([SafeDiv(x#lia_1, y#lia_1) = 5,y#lia_1 != 0;int(1..)])

--

Final model:

find x: int(1..10)
find y: int(2..4)
find x#lia_1: int(1..10)
find y#lia_1: int(2..4)

such that

and([SafeDiv(x#lia_1, y#lia_1) = 5,y#lia_1 != 0;int(1..)])
