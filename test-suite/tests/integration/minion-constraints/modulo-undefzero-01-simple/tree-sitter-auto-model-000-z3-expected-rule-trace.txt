Model before rewriting:

find x: int(1..10)
find y: int(2..4)

such that

x % y = 3

--

x
   ~~> select_representation ([("ReprGeneral", 10000)])
x
new variables:
  find x#bv_1: int(1..10)

--

y
   ~~> select_representation ([("ReprGeneral", 10000)])
y
new variables:
  find y#bv_1: int(2..4)

--

x
   ~~> smt_int_bv_variable ([("Smt", 9500)])
x#bv_1

--

y
   ~~> smt_int_bv_variable ([("Smt", 9500)])
y#bv_1

--

x#bv_1 % y#bv_1
   ~~> mod_to_bubble ([("Bubble", 6000)])
{SafeMod(x#bv_1,y#bv_1) @ y#bv_1 != 0}

--

{SafeMod(x#bv_1,y#bv_1) @ y#bv_1 != 0} = 3
   ~~> bubble_up ([("Bubble", 8800)])
{SafeMod(x#bv_1,y#bv_1) = 3 @ y#bv_1 != 0}

--

{SafeMod(x#bv_1,y#bv_1) = 3 @ y#bv_1 != 0}
   ~~> expand_bubble ([("Bubble", 8900)])
and([SafeMod(x#bv_1,y#bv_1) = 3,y#bv_1 != 0;int(1..)])

--

Final model:

find x: int(1..10)
find y: int(2..4)
find x#bv_1: int(1..10)
find y#bv_1: int(2..4)

such that

and([SafeMod(x#bv_1,y#bv_1) = 3,y#bv_1 != 0;int(1..)])
