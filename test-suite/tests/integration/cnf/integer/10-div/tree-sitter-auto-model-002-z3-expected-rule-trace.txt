Model before rewriting:

find a: int(1..10)
find b: int(1..10)
find c: int(-100..100)

such that

(a / b) = c

--

c
   ~~> select_representation ([("ReprGeneral", 10000)])
c
new variables:
  find c#lia_1: int(-100..100)

--

a
   ~~> select_representation ([("ReprGeneral", 10000)])
a
new variables:
  find a#bv_1: int(1..10)

--

b
   ~~> select_representation ([("ReprGeneral", 10000)])
b
new variables:
  find b#bv_1: int(1..10)

--

c
   ~~> smt_int_lia_variable ([("Smt", 9500)])
c#lia_1

--

a
   ~~> smt_int_bv_variable ([("Smt", 9500)])
a#bv_1

--

b
   ~~> smt_int_bv_variable ([("Smt", 9500)])
b#bv_1

--

(a#bv_1 / b#bv_1)
   ~~> div_to_bubble ([("Bubble", 6000)])
{SafeDiv(a#bv_1, b#bv_1) @ b#bv_1 != 0}

--

{SafeDiv(a#bv_1, b#bv_1) @ b#bv_1 != 0} = c#lia_1
   ~~> bubble_up ([("Bubble", 8800)])
{SafeDiv(a#bv_1, b#bv_1) = c#lia_1 @ b#bv_1 != 0}

--

{SafeDiv(a#bv_1, b#bv_1) = c#lia_1 @ b#bv_1 != 0}
   ~~> expand_bubble ([("Bubble", 8900)])
and([SafeDiv(a#bv_1, b#bv_1) = c#lia_1,b#bv_1 != 0;int(1..)])

--

Final model:

find a: int(1..10)
find b: int(1..10)
find c: int(-100..100)
find c#lia_1: int(-100..100)
find a#bv_1: int(1..10)
find b#bv_1: int(1..10)

such that

and([SafeDiv(a#bv_1, b#bv_1) = c#lia_1,b#bv_1 != 0;int(1..)])
