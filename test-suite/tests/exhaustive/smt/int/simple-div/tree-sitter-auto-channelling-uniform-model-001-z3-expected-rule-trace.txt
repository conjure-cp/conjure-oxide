Model before rewriting:

find a: int(0..4)
find b: int(0..4)

such that

(a / b) = 2

--

a
   ~~> select_representation ([("ReprGeneral", 10000)])
a
new variables:
  find a#lia_1: int(0..4)

--

b
   ~~> select_representation ([("ReprGeneral", 10000)])
b
new variables:
  find b#lia_1: int(0..4)

--

a
   ~~> smt_int_lia_variable ([("Smt", 9500)])
a#lia_1

--

b
   ~~> smt_int_lia_variable ([("Smt", 9500)])
b#lia_1

--

(a#lia_1 / b#lia_1)
   ~~> div_to_bubble ([("Bubble", 6000)])
{SafeDiv(a#lia_1, b#lia_1) @ b#lia_1 != 0}

--

{SafeDiv(a#lia_1, b#lia_1) @ b#lia_1 != 0} = 2
   ~~> bubble_up ([("Bubble", 8800)])
{SafeDiv(a#lia_1, b#lia_1) = 2 @ b#lia_1 != 0}

--

{SafeDiv(a#lia_1, b#lia_1) = 2 @ b#lia_1 != 0}
   ~~> expand_bubble ([("Bubble", 8900)])
and([SafeDiv(a#lia_1, b#lia_1) = 2,b#lia_1 != 0;int(1..)])

--

Final model:

find a: int(0..4)
find b: int(0..4)
find a#lia_1: int(0..4)
find b#lia_1: int(0..4)

such that

and([SafeDiv(a#lia_1, b#lia_1) = 2,b#lia_1 != 0;int(1..)])
