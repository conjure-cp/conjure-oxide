# Partitions

## What are Partitions

Please see the [Essence Reference](/reference/domains/partitions.md).

For a good example of a partition in use, see the [Social Golfers](https://www.csplib.org/Problems/prob010/models/SocialGolfersProblem.essence.html) problem (CSPLib.org, problem #10).

## Note on Implementation

> As of writing (26/04/2026): no partition operators are implemented in conjure-oxide, partitions cannot be parsed using the native parser, and there is no support for rewriting or solving with partitions.
