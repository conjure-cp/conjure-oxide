This page describes the horizontal set rules currently implemented in conjure-oxide. Horizontal rules rewrite set expressions without choosing a set representation. The Rust snippets and module names below refer to `crates/conjure-cp-rules/src/types/set/horizontal`.

# Comprehension notes

The notation `i <- A` generates values of `i` from `A`. In particular:

* `and([P(i) | i <- A])` requires `P(i)` for every generated value.
* `or([P(i) | i <- A])` requires `P(i)` for at least one generated value.

These are the `And` and `Or` skip operators on comprehensions in the Rust AST.

# Boolean set relations

The rules below are registered in `equals.rs`, `neq.rs`, `subset.rs`, `subseteq.rs`, `supset.rs`, and `supseteq.rs`.

| Expression | Rewrite |
| --- | --- |
| `A = B` | `A subsetEq B /\ B subsetEq A` |
| `A != B` | `!(B = A)` |
| `A subset B` | `(A subsetEq B) /\ (A != B)` |
| `A supset B` | `B subset A` |
| `A supsetEq B` | `B subsetEq A` |
| `A subsetEq B` | `and([i in B \| i <- A])` |

For example, set equality is lowered to two subset checks in `equals.rs`:

```rust
fn eq_to_subset_eq(expr: &Expression, _: &SymbolTable) -> ApplicationResult {
    match expr {
        Eq(_, a, b)
            if matches!(a.as_ref().return_type(), Set(_))
                && matches!(b.as_ref().return_type(), Set(_))
                && !is_set_valued_index(a)
                && !is_set_valued_index(b) =>
        {
            let expr1 = SubsetEq(Metadata::new(), a.clone(), b.clone());
            let expr2 = SubsetEq(Metadata::new(), b.clone(), a.clone());
            Ok(RuleEffect::pure(And(
                Metadata::new(),
                Moo::new(matrix_expr![expr1, expr2]),
            )))
        }
        _ => Err(RuleNotApplicable),
    }
}
```

`subseteq_set` builds an expression-generator comprehension. Set-valued matrix indices are left alone so representation-specific rules can handle them later.

`concat.rs` also contains subset-equality rewrites:

* `A subsetEq (B intersect C)` becomes `(A subsetEq B) /\ (A subsetEq C)`.
* `union_subseteq` matches `(A union B) subsetEq C`. 

# Set operations in comprehensions

`union.rs` rewrites a comprehension generator over a union by combining two comprehensions. The second branch excludes values already generated by the first set, avoiding duplicates:

```rust
let (comprehension1, _) =
    replace_expression_generator_source(comp.as_ref(), &gen_decl, a.clone().into());
let (mut comprehension2, b_ptr) =
    replace_expression_generator_source(comp.as_ref(), &gen_decl, b.into());

comprehension2
    .qualifiers
    .push(ComprehensionQualifier::Condition(Expr::Not(
        Metadata::new(),
        Moo::new(Expr::In(
            Metadata::new(),
            Moo::new(Expr::Atomic(Metadata::new(), Atom::new_ref(b_ptr))),
            a,
        )),
    )));

return Ok(RuleEffect::pure(Expr::Flatten(
    Metadata::new(),
    None,
    Moo::new(into_matrix_expr!(vec![
        Expr::Comprehension(Metadata::new(), comprehension1.into()),
        Expr::Comprehension(Metadata::new(), comprehension2.into())
    ])),
)));
```

`difference.rs` rewrites a comprehension generator over `A - B` to generate from `A` and add a condition excluding members of `B`:

```rust
let (mut comprehension, a_ptr) =
    replace_expression_generator_source(comp.as_ref(), &gen_decl, a.into());
comprehension
    .qualifiers
    .push(ComprehensionQualifier::Condition(Expr::Not(
        Metadata::new(),
        Moo::new(Expr::In(
            Metadata::new(),
            Moo::new(Expr::Atomic(Metadata::new(), Atom::new_ref(a_ptr))),
            b,
        )),
    )));
```

The same module lowers direct membership in a difference:

```rust
// x in (a - b) ~~> (x in a) /\ !(x in b)
let in_a = Expr::In(Metadata::new(), member.clone(), a.clone());
let in_b = Expr::In(Metadata::new(), member.clone(), b.clone());
Ok(RuleEffect::pure(Expr::And(
    Metadata::new(),
    Moo::new(conjure_cp::matrix_expr![
        in_a,
        Expr::Not(Metadata::new(), Moo::new(in_b))
    ]),
)))
```

`generator.rs` handles set-valued expression generators generally. It replaces the expression generator with a generator over the source's element domain and adds a membership condition. An `Or` comprehension with a constant source is deliberately left for the dedicated existential-comprehension rule.

# Membership and cardinality

`membership.rs` implements these compound-set and literal cases:

| Membership expression | Rewrite |
| --- | --- |
| `x in (A intersect B)` | `(x in A) /\ (x in B)` |
| `x in (A union B)` | `(x in A) \/ (x in B)` |
| `x in {a, b, ...}` | `or([x = a, x = b, ...])` |

For an empty set literal, membership becomes `false`. 

`cardinality.rs` handles cardinality of a compound set expression. It leaves atomic set references, set-valued indices, and non-set expressions to other rules. For a supported compound set, it sums one for each generated member:

```rust
let mut comprehension = builder
    .expression_generator(name, source.as_ref().clone())
    .with_return_value(1.into());
comprehension.skip_operator = Some(ACOperatorKind::Sum);

Ok(RuleEffect::pure(Expr::Sum(
    Metadata::new(),
    Moo::new(Expr::Comprehension(
        Metadata::new(),
        Moo::new(comprehension),
    )),
)))
```
